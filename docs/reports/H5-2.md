## 新发现的问题与限制

- **旧容器迁移**：新 Compose 容器名与旧栈不同；旧 `echomind-*` 仍可能占用 6379/8001。迁移需先停旧栈、保留数据卷，步骤见 `docs/naming.md`。
- **数据卷**：Compose 项目名不变时命名卷可复用；不要执行 `docker compose down -v`。
- **密码**：新 `.env.example` 使用 `cartcare123`；已有 `.env` 可保留旧密码，只要 `REDIS_URL` 与 Redis 容器一致。
- **镜像未重建**：Dockerfile 用户/healthcheck 改动未在容器中验证；H5-3 前重建并检查 `/ready`。
- **历史旧名**：`evaluation/answerability/**`、`evaluation/topology_eval.py`、历史报告/CHANGELOG 保留 `echomind-*`/`ECHOMIND_*`，属于历史证据，不是当前运行路径。
